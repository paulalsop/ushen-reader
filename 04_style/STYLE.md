# STYLE — 写作风格定义（v11 · 人话、现实常识、想象力与标题辨识度）

## 一句话基调
**世界是真的，人是不靠谱的。**
神话认真辽阔，角色全体沙雕；笑要无厘头，泪要后知后觉。
定位：山海经悬疑公路轻喜剧——每章可以好笑，但必须有选择、代价与状态变化。

## 一、笑点机制（工具箱，不是配额）

五类可用，**不强制每章凑数**：

1. **反差**：神话人物先找不正经的那一面。
2. **拆解崇高**：大事件有小细节，大人物有小毛病。
3. **职业病**：苏慕编辑脑、狗系统营业腔、古人逻辑撞现代常识。
4. **复读梗**：同一动作/口癖再次出现时，必须升级含义或转成泪点；原样复读不算。
5. **误会链**：靠信息差滚雪球，不靠解说。

铁律：
- 笑话必须长在人物目标与行动上；删掉旁白解释后仍成立。
- **禁止解释笑点**：不许写「这件事很好笑」「记忆点捕获」「结构评分」之类标注。
- 一章可以无笑点；严肃章不得为了过门硬塞吐槽。
- 同一口头禅跨章高频复用即退稿（尤其狗系统「感谢您的理解／重复领取概不补发」）。

## 二、泪点机制（双层梗）

- 先笑，后沉默；一次只给一刀，给完立刻翻篇，不许煽情段落。
- 泪点三味：来不及、回不去、甩不掉。
- 禁止：哭腔旁白、「他流下了眼泪」式直给、连续两章放泪。

## 三、知识机制（必须改变行动）

- 真《山海经》条目随剧情变现：先遇事，后出书。
- 苏慕可以背原文，但必须用在刀刃上——背到一半被打断，比背完更好笑。
- **知识必须会错**：信错条目，付真代价；校对自己也会制造新后果。
- 单纯背书、换说法复述，不算知识推进。无知识章允许（填「无」）。

## 四、叙事硬门（比笑点更重要）

每章必须同时满足：

1. **即时目标**：谁现在想得到什么？
2. **阻力意志**：阻力来自另一个人的意志或环境反制，不是作者暂不公布信息。
3. **选择**：主角或关键角色作出不可兼得的选择。
4. **状态变化**：章末与章初相比，人物/关系/资源/目标至少一项不同。
5. **持续后果**：本章选择立即付出代价，或明确将在后续章兑现。
6. **不可替换场面**：至少有一处由本章神兽、地貌、条目或时代规则主动造成并改变行动的场面。把神兽换成普通人、把神山异泽换成普通村镇后仍能原样成立，视为想象力不合格。

「看见异常并继续东走」不算状态变化。
「又发现一条线索」若未改变判断或行动，不算推进。

### 想象力与不可替换性（硬门）

- 神话不能只做外皮。赤鱬“音如鸳鸯”、山会翻身、迷榖指路等原生特征，必须参与误判、行动、转折或代价；只让异兽像普通人一样坐着谈心，换成任意会说话的人仍成立，直接退稿。
- 每章至少有一个**意外但回头看合理**的场面机制，并真正改变人物下一步。怪异外形、冷僻名词、突然发光和一句俏皮话若不改变因果，只是装饰，不算想象力。
- 任务卡锁定承接、目标、边界和章末状态，不得把全部对白、笑点、转折与解决方式预写死。正文若只是逐项扩写任务卡，读者会先于人物知道每一步，视为“任务卡影子稿”。
- 连续章节不得反复使用“到场询问—分类记录—总结结论—原地等待”的同一种解决结构。四章一波至少更换两种以上冲突机制，如误导、交换、追逐、仪式失败、环境反制、关系误判、物件失控或知识反噬。
- 喜剧不能长期只靠招摇说错话、系统提醒、白耳补冷句。笑点应从神异能力、身份关系和办事方式互相咬合中生长，并对场景产生后果。
- 新奇不等于随意。任何超常现象都要有前因、边界和代价；最好的想象力，是前文已给出的普通细节在关键时刻以意外方式发挥作用。

## 五、语言规矩

- 短句为主，长短交错；对话驱动；叙述人不端着。
- **短句不是碎句。** 省字不能省掉对象、动作、先后关系和人物真实意图。读者若必须把连续三四个词组重新拼成长句，说明作者把“利落”写成了电报。
- 现代梗只许从两个口子进：苏慕的脑子、狗系统的嘴。古人嘴里不出现代词。
- 系统声道必须可判：写明“脑内／心里／私语”即只有苏慕能听；写明“共听／外放／从眉心传出”即百丈内同行者可听。古人不得回应私语；共听只传系统主动发言，不泄露苏慕心念、记忆与残册页面。群体场景首次切换声道必须落一笔提示。
- 系统首次在某个角色面前外放，必须写出**触发原因、可感知的声音出现、角色的本能反应、苏慕或系统的边界说明**。白耳、招摇可以因亲历逐渐接受，但不能第一次听见脑中陌生声音便毫无惊疑；后续熟人场景可简写，新听众仍须有符合身份的反应。
- 白耳不读心、不全知。它只能报告亲历、确知来源与尚存记忆；记忆到哪里结束，必须说清到哪里。招摇也不能因山神身份读取苏慕心念。
- 人物复述重要消息时，优先区分：亲眼所见、明确来源的听说、猜测、不知道。发现说错须当场承认，不得用新故事悄悄覆盖旧话。
- 结绳、刻痕、骨符、泥形、脚印与实物提示都不是通用文字。它们只能提醒停步、指认对象或帮助当事人记忆；完整含义必须由本地持有人、制作人或现场见证者口述并允许对方回述。
- 世界内交换写兽牙、栗粮、盐、藤席、劳力等具体物，不写售价、收费、高价、购买、退货等现代商业表达。可以有摊、有交换、有欺骗，但必须长在时代内的物与人上。
- 禁止：网络烂梗直给、屎尿屁、段子合集化。
- 普通章正文原则上不少于3000字；重要冲突章3500–4500字。统一统计第一个 `---` 前的正文字符数，不用文件字节数，也不含章末自报。润色不得以缩水为目标。
- 修改既有章节必须先记录改前正文字符数。除非用户明确要求精简，改后正文原则上不得少于改前；删除重复、残段或废话后，要用有效动作、空间、关系、选择与后果补足，不能把完整场景修成提纲。
- 扩写只补有效内容：具体动作、空间关系、人物选择、关系变化、后续会兑现的伏笔。禁止同义反复、审计报告体和机械凑字。
- 少用机械的“A不是B，是C”；需要纠偏时尽量让事实、动作或他人反应自己完成。
- 结尾方式任选其一：决定 / 后果 / 关系变化 / 余味意象 / 强钩。**不强制章末悬念句**；连续两章不得用同一类空悬念收尾。

### 人话优先（硬门）

- 人物在当场说话，首先要让同伴听懂“现在做什么、为什么、接下来怎么办”，不能优先追求像标语、判词或金句。
- 危急场景允许短促，但必须保住宾语与行动顺序。例如可以说“先送你回山，东边以后再走”，不能压成“不东进。东进的账以后算”。
- **“账”不是万能代词。** 只有确实涉及债、承诺、责任、旧怨、交换或可核事项时才用“账”。禁止用“东进的账、进雾的账、回头的账、休息的账”替代“往东走的事、进入雾里的安排、是否回头、什么时候休息”。人物越着急，越应说清眼前行动，而不是突然变成账房或审计员。
- 禁止把上一句末尾的词机械拿来当下一句主语，例如“缝硬。硬里没有水渗”“声可以记。记完不许离绳”。这种词尾接龙会让叙述像模型在续词，不像人在观察和说话。
- 禁止把完整判断拆成连续标签，例如“干坡有水声。水声骗子”。应让角色用自己的口气说成完整意思，如“这种干坡上的水声会骗人，不能乱追”。
- 比喻、冷句和俏皮话不能代替安全指令。若真正需要表达的是“不要离开绳子单独找水”，就先把这句话说完整；“把自己变成下一只鸟”只能在上下文已经明确、人物确实会这样说时作为补充，不能让读者猜行动规则。
- 白耳可以话少，但不能少宾语；苏慕可以抠字，但不能把同伴安危说成报告；招摇可以稚气、学舌、自称“本座／本灯”，但句子仍须表达完整意思；系统可以有条目腔，其他人物与旁白不能被它同化。
- 所有关键对白必须做一次朗读测试：盖住人名后仍像该人物；单独读出仍能明白对象与动作；正常人处在同一场景里确实可能这样说。只要“意思勉强能猜到，但不像人会这么说”，即判不通过。

典型修正方向（示例只示范原则，不要求逐字照抄）：

- 机械：`总之不东进。东进的账，送你回去以后再算。`
  人话：`总之不能继续往东走。先送你回去，等你安稳了，我们再商量东行的事。`
- 机械：`缝硬。硬里没有水渗。`
  人话：`石缝摸上去又干又硬，一点水也没渗出来。`
- 机械：`不追声。声可以记。记完不许离绳。`
  人话：`别追那个水声。把方向记下来，但谁也不许离开绳子单独去找水。`
- 机械：`本灯记下：干坡有水声。水声骗子。`
  人话：`本灯记住了。这种干坡上的水声会骗人，不能乱追。`

### 现实常识优先（硬门）

- 神话世界可以神异，人物的身体、时间、距离、负重、伤势、饥渴与昼夜仍须可信。神异若改变常识，正文必须先建立能力、限制与代价，不能在需要赶路或救场时临时出现。
- 出现具体距离与天数时，必须反算每日路程。崎岖山地、无成路、携带物资的普通人，日行二十至四十里已是正常推进；伤员、老人、幼童、探路、雨雾、涉水与爬坡还要更慢。连续日行百里不能当普通步行速度，除非有坐骑、运输神异、成熟道路或强行军，并写出代价。
- 《山海经》“又东三百里”表示两山之间的地理间隔，不等于人物三天便能走到。类似三百里山路，未经特殊条件说明，不得写成普通人连续三日步行抵达。
- 每次跨日或跨地推进都要核对：白昼可用时间、扎营与守夜、取水进食、路线绕行、伤势变化、携带物重量、队伍最慢者。不能只按直线距离除以天数。
- 物理细节也要服从常识：声音受距离与风向影响，火与烟需要燃料和通风，湿物不会瞬间干，伤口与体力不会换章复原，重物必须有人搬，手中物与人物站位不能无过渡改变。
- 任何数字只要同时出现“距离、时间、速度／次数、容量、人数”中的两项，就要推算第三项；算不通便改数字、改耗时或补充可信条件，不能依赖读者忽略。

## 六、格式与标题

- 文件名统一为 `第NNN章_标题.txt`；首行统一为 `第NNN章 标题`。除文件名因兼容性省略的标点外，章号与标题用字必须对应。
- 标题应来自本章最具体的冲突、动作、物件或关系变化，单独读也要自然、清楚、有画面。避免“方案一”“经济学”“风波”“报告”“处理结果”等制作腔，也不要用与正文无关的怪词硬装新奇。
- 标题须在正文定稿后反查：读者能指出它对应哪一幕；不能剧透整章答案；与相邻章节不重复同一模板。只概括主题、像任务标签或找不到具体落点的标题，一律重拟。
- 标题通常以六至十二个汉字为宜，长度不是硬配额，但两至四字标题必须具有不可替换的高辨识度。`三只、约、东行、页边、旧路、到家、继续、钱来`这类裸地点、裸动作或单一标签，离开章号便无法辨认本章内容，不得直接作为定稿标题。
- **短不等于准。** 标题至少应同时包含“具体对象／意象”与“本章独有变化”中的两项，例如不是只写“旧路”，而要写清旧路发生了什么；不是只写“钱来”，而要让读者知道钱来山本章最异常的场面。
- 每章定稿后至少拟三个标题候选，其中至少两个为六至十二字，再依据画面、人物声音、剧透程度和相邻章去重选择最终标题。
- 正文只保留一个完整版本；禁止重复段、残段、多个结尾并存。
- 章节文档统一使用 UTF-8：首行为章号与标题，空一行后进入正文；正文结束后空一行写唯一分隔线 `---`，再空一行写一份【章末自报】。第一个 `---` 后不计正文篇幅；发布时剔除，生产稿必须保留并与正文事实一致。

## 七、幽默红线

- 不嘲笑苦难：可以笑神的架子，不笑人的穷苦。
- 不拿泪点当笑点：双层梗的下层永远是真的。
- 苏慕可以怂、可以贫，不许贱；狗系统可以狗，不许坏。

## 文风锚点
第001—100章是首要呼吸、密度与人物声音锚点；第101—155章已依同一标准统一，可作为卷二连续性锚点。后续正文不得突然转为提纲体、审计体或短章压缩体。

## 八、审计后追加硬门（v12）

### 1. 让苏慕真的可能判断错

- 每个 10—20 章单元至少安排一次“校勘直觉失效”：不是发现原文有瑕疵就算，而是苏慕据此作出行动，行动造成别人受伤、错过时机、失去资源或关系受损。
- 错误不能在同一章用一句“其实只是边界不同”洗掉。后果至少延续到下一章，并改变他的下一次判断。
- 失败不必让主角显得愚蠢，但必须让他的职业优势有盲区：过度求证、过度克制、相信旧版本、低估人的意志，都可以成为具体失误。

### 2. 单元必须改变冲突机制

- 连续四章内不得反复使用“到场询问—分类记录—总结—等待”。四章至少换用两种机制：误导、交换、追逐、环境反制、关系误判、物件失控、仪式失败或知识反噬。
- 向导不是移动的百科全书。每个向导有自己的目的、害怕的事和不能说的边界；他提供信息时必须同时推动自己的选择，必要时可以拒绝、说错或要求交换。
- 一个场景若把神兽换成普通人、异泽换成普通村，动作和解法仍能原样成立，说明神话特征没有进入因果，必须退回重写。

### 3. 长线谜题要关账

- 每卷同时面向读者开放的大谜不超过三条；新谜出现前，任务卡要写明本章推进或关掉哪一条旧谜。
- 每 30 章至少完成一条可指认的谜题阶段：部分揭示、证据推翻或代价性确认三选一。只写“继续记着”不算兑现。
- 章末必须留下事实、决定或后果，不能替读者把情绪解释完；连续两章不得用同一类空悬念收尾。

### 4. 语言和系统口癖限频

- “A 不是 B，是 C”“可以……不能……”等对冲句式同一章各不超过一次；关键判断优先用动作、证据和他人反应完成。
- 词尾接龙不得连续出现；安全指令必须保留对象、动作和先后关系，不能用标签或比喻代替。
- 系统固定段子不能占每章固定位置；同一口癖十二章内不重复，严肃场景可以完全沉默。招摇的自称只在关系或状态发生变化时使用，不以“本座”填充语气。

### 5. 病情、伤势和倒计时必须变化

- 持续性危机每两至三章至少出现一项可观察变化：症状、体力、饮水、照护方式、风险等级或可行选择发生变化。
- 若病情暂时没有好转，也要给出可信的病程判断、照护边界或新的选择；不能只重复“仍高热、仍昏沉”。
- 任何改善都必须有条件和代价，任何恶化都必须影响行动，不能只用于章末煽情。

### 6. 生产稿与读者稿分离

- `章节/` 是生产稿，可以保留唯一一份【章末自报】；自报不得混入正文，不得在正文中出现“下章、待审计、禁词通过、雷编号”等制作语言。
- 发布必须经过 `build_reader.py`，构建产物不得包含【章末自报】或生产分隔线；直接把生产稿当读者稿交付视为格式不合格。
- 正文内部用空行完成场景换气；`---` 只允许出现在正文结束与章末自报之间，避免阅读器把制作分隔线当情节结构。
