# SOP — 生产流程（v11 · 人话、常识、想象力与标题验收版）

## 角色分工
| 角色 | 职责 |
|------|------|
| **老板（人）** | 终审：基调裁决、合并放行 |
| **主审 Agent** | 出任务卡、逐章审稿、更新账本与规范 |
| **写作 Agent** | 按任务卡写正文，只改授权章节，不擅改设定 |

## 并行纪律

- 可以连续推进多章，但必须**一章一审、一章一提交、一章一推送**；不得攒十章后一次性合并。
- 既有章节必须整章逐句通读后再交付；关键词扫描、脚本检查与批量替换只能辅助，不能代替人工语境审读。
- 写作前先确认工作树与远端状态。工作树不干净时，只处理自己被授权的文件，不覆盖、不删除、不暂存其他agent的修改。
- 每章只暂存该章文件。文档更新另开独立提交，不与正文章混合。
- 推送冲突时先同步远端，再只解决自己章节的冲突；不得用重置、强推或整树覆盖清除他人工作。
- 同一章同一时刻只交给一个agent。后章不得假设前章尚未提交的新事实。

## 经验回写（强制）

- 用户或主审指出的可复用问题，不能只改当前句。开始下一批正文前，必须把经验写回规范，让后续agent能直接执行。
- 回写分三层：`STYLE.md` 写不可违背的原则，`WRITING_GUIDE.md` 写识别方法与改写步骤，本 SOP 写任务卡检查、质量门或退稿条件。
- 只沉淀可复用的写作规律，不把单章剧情偶然写成全局禁令。规范更新须单独提交，不与章节正文混在同一次提交中。

## 投喂包（写作 Agent 开写前必发，导演按章裁剪）
1. `00_canon/00_CORE.md`
2. `01_world/WORLD.md`（时代红线必读）
3. `04_style/STYLE.md`
4. `02_characters/CAST.md` 本章出场人物卡（只发相关卡）
5. `06_continuity/LEDGER.md` 全文
6. 已合并正文最近 3 章（文风与连续性锚点）
7. 第001—100章中与本章场景类型相近的 1 章（首要呼吸、密度与人物声音锚点）
8. 本章任务卡（模板见下）

## 剧情别出心裁（强制 · 防套路）
任务卡只锁承接、目标、边界与章末状态，不能预写完整对白、全部笑点和唯一解法。写作 Agent 开写前须提出三个不同的场景机制，完成换皮测试后选择一个。每章至少一处让读者意外但仍自洽、并实际改变行动或后果的设计，例如：
- 用错的知识碰巧救场／用对的知识反而惹祸
- 祥瑞办事像办业务，神异像事故现场
- 护送／对峙／谈判用「礼节／误会／流程」推进，不靠战力升级
- 强钩要具体（一个动作、一句错位），禁止空悬念

以下不算别出心裁：异兽只换外形；突然发光；新造冷僻名词；招摇再说错一句；白耳再补一刀；系统再提醒一次；人物开会后得出任务卡早已写明的结论。

导演审稿必须做三项检查：

1. **换皮测试**：神兽换普通人、异泽换普通村仍可原样成立 → 退稿重写场面。
2. **任务卡影子测试**：正文逐项照抄任务卡的对白、笑点、转折和结论 → 退稿重新发明过程。
3. **四章去重测试**：同一波不得连续用“询问—分类—总结—等待”推进；至少使用两种不同冲突机制，且神异环境或能力必须主动参与一次因果。

## 衔接与出场（强制 · 防凭空、防捣腾）
1. **出场有因**：任何人（含兽）入场须有上一章钩子、行程、呼喊、跟随、回村等理由。
2. **状态连续**：地点／队伍构成／伤势光晕／手中物件／倒计时，必须与 LEDGER + 上章末对齐。
3. **一人一事一时**：同一章内禁止无必要地来回倒腾。
4. **并行写作护栏**：同批后章不得假设前章未写明的新事实。
5. **退稿标准**：凭空加人、时空跳跃无过渡、同一冲突反复横跳、上章钩子下落不明 → 一门不过即退。
6. **地图门（书即行程单）**：卷一锁定南山经䧿山系西→东（见 `cards/V01.md` 行程地图）。禁止跳山/瞬移。

## 任务卡模板（导演逐章填写）
```
【第 NNN 章】标题：
一、本章承接：上章结尾状态（地点/人物/资源/目标）
二、行程：上一站 → 本章所在 → 章末指向（原文里程；回程/快进须写明）
三、戏剧问题：谁现在想得到什么？
四、人物压力：这件事咬中了他的哪种欲望、恐惧或旧债？
五、核心选择：他必须在什么与什么之间选择？
六、场景转折：哪一刻使原计划失效？（1–2 个结果，禁止列 3–5 个待办动作）
七、状态变化：章末人物/关系/资源/目标有什么不同？
八、持续后果：本章选择立即付出什么，并将在何章继续兑现？
九、线索增量：新观察改变了哪个旧判断？无则 —
十、出场人物（各附：声音、禁用句、本章动机）：
十一、知识用途：改变行动 / 造成误判 / 兑现后果；无则 —
十二、喜剧发动机：人物行为或关系如何自然产笑？无则 —
十三、泪点（如有，一刀即止）：
十四、雷（埋/爆，登记编号）：
十五、禁词与时代红线提醒：
十六、结尾方式：决定 / 后果 / 关系变化 / 意象 / 强钩
十七、字数：普通章≥3000；重要冲突章3500–4500（统计到首个---）
十八、信息边界：亲见/听说/猜测/未知；持有人；外传权限；系统声道
十九、对白人话检查：本章哪些话承担行动指令或关系变化？须写清对象、先后与真实意图；不得压成账目腔、标语腔或谜语腔
二十、现实常识：距离÷天数所得日行里程；道路/天气/负重/伤势/最慢者；扎营、取水、休息与物资是否成立
二十一、改稿篇幅：改前正文字符数 → 目标字符数；无明确精简指令时不得缩水（新章填“新写”）
二十二、标题候选与落点：正文定稿后拟三个候选（至少两个六至十二字）；各自对应哪一幕；最终标题为何自然、有画面、不过度剧透且不与相邻章套同一模板
二十三、不可替换机制：本章哪项神兽/地貌/条目特征主动改变行动？换成普通人或普通村为何不能成立？
二十四、三个候选场景：列出三种不同过程，只锁选中方案的因果，不预写完整对白
二十五、去重检查：最近三章分别用什么冲突与解决机制？本章如何避免再次询问、分类、总结、等待？
```

## 交付格式（写作 Agent 交稿）
- 普通章正文原则上不少于3000字；重要冲突章3500–4500字。统一统计第一个 `---` 前的正文字符数，不用文件字节数，也不含章末自报。
- 旧章改稿须同时报告改前、改后正文字符数。未经明确授权，改后原则上不得少于改前；删除废话后应补成更有效的场景内容，不得用重复句凑数。
- 文档必须为 UTF-8：首行 `第NNN章 标题`，空一行后写正文；正文后只保留一个 `---`，再空一行写一份【章末自报】。文件名、首行与任务卡标题须一致。
- 章末自报（供导演/账本，**不当读者正文**）：
  - 新立事实
  - 选择与不可逆后果
  - 线索已知结论（写清「读者已知什么」，禁止后章再当新发现）
  - 雷台账变动
  - 校勘进度（如有）
  - 禁词自检

## 质量门（逐章对照，一门不过即退稿）
| 门 | 标准 |
|----|------|
| 设定门 | 不违背 CORE/WORLD/CAST 任一条；新事实登记 |
| 时代门 | 无纸钱官府考试客栈等越时代物件；无成熟通用文字体系。残册与私人符号按 WORLD 边界处理 |
| 载体门 | 结绳、刻痕、骨符、泥形、脚印与实物不能自行讲完整句；须有持有人/见证人口述 |
| 声道门 | 系统私语/共听清楚；古人不回应私语；白耳与招摇不读心、不全知。首次对某角色外放须有触发、显现、反应、确认；新听众不得无缝接受 |
| 泄密门 | 本卷禁词零出现；深层异常未超配额（WORLD §4） |
| 因果门 | 有即时目标、阻力意志、核心选择；章末状态≠章初 |
| 后果门 | 选择付出代价或明确将兑现；「继续东走」不算 |
| 线索门 | 新线索须改变判断或行动；只重复气氛=退 |
| 喜剧门 | 若有笑点须长在人物行动上；有解释笑点句=退；万能吐槽模板=退 |
| 想象门 | 至少一项既有神异特征主动改变行动、误判或后果；通过换皮测试与任务卡影子测试；同波冲突机制不机械复用。只换异兽外形、突然发光或照卡扩写=退 |
| 衔接门 | 出场有因；状态与上章/LEDGER连续；无凭空加人 |
| 地图门 | 行程与 V01 地图一致；无跳山；已校山掠影不重案 |
| 常识门 | 距离、天数与日行速度能互算；道路、昼夜、负重、伤势、取水、休息及队伍最慢者均已计入。普通人不得无依据连续日行百里；神异例外须有既定边界与代价 |
| 知识门 | 若有知识须改变行动/造成误判/兑现后果；无知识允许 |
| 文风门 | 符合 STYLE：短句对话驱动、内心戏≤20%；无审计腔、提纲腔、机械“A不是B，是C” |
| 人话门 | 短句仍须有对象、动作与必要连接；关键对白能自然说出口；无万能“账”字、词尾接龙、标签式碎句或用比喻代替安全指令。意思能猜到但人物不会这样说，也须退稿 |
| 密度门 | 正文达到目标篇幅；旧章有改前/改后统计且未经授权不缩水；扩写均为动作、关系、空间、伏笔或后果，无同义反复凑字 |
| 标题门 | 定稿后有三个候选且至少两个六至十二字；最终标题对应正文具体场景，单独读自然、有画面、不过度剧透。两至四字标题须具高辨识度；裸地点、裸动作、制作标签、怪词硬凑或相邻章模板复用=退 |
| 格式门 | UTF-8；文件名、首行章号、标题一致；首行后空一行；正文后仅一个 `---` 和一份章末自报；标题变更时旧文件已同步重命名，无重复段、旧标题副本和多版本结尾 |
| 题眼门 | 本批至少一处呼应「人/记」题眼（只演示，可极轻） |

### 场景验收十问（导演审稿时自问）
1. 此刻谁想要什么？
2. 阻力来自另一个人的意志，还是仅来自作者暂不公布信息？
3. 场景中谁做了选择？
4. 选择后失去了什么？
5. 删除本场，后文是否完全不受影响？如果是，删场。
6. 把苏慕换成任意聪明人，场景是否仍成立？如果是，主线没有咬住人物。
7. 笑点之后是否还有一句解释它为什么好笑？有则删解释句。
8. 把关键对白单独朗读，现实中的这个人物会在此刻这样说吗？若只是意思能猜到，或必须替作者补宾语、顺序与因果，退回按完整人话重写。
9. 把神异暂时拿掉后，人物的步行速度、体力、伤势、负重、取水、昼夜与物理动作仍成立吗？不成立则改数字、改耗时，或补出已建立的神异条件与代价。
10. 把神兽换成普通人、神异地貌换成普通村，本场是否还能原样成立？若能，说明神话只是皮；须让既有神异特征进入因果并制造一次意外但合理的变化。

## 单元级指标（每 10–20 章一案，案末审计）
- **喜剧**：1 个人物性喜剧发动机（建立→升级→变味或回收）；2–4 个真正承担场面的喜剧段落。
- **知识**：2–4 条核心条目；至少两次影响决策、误判或代价。
- **钩子**：仅在转折点配置 2–4 个强钩；其余章可用决定/后果/关系变化收束。
- **不可逆后果**：至少一次由主角选择造成的持续损失（信任、资源、可选道路、关系、目标）。
- **线索增量链**：观察 → 假设修正 → 因假设行动 → 行动带来新风险。禁止五章内把同一答案换说法重讲。

## 合并与账本
- 过门稿件进 `章节/第NNN章_标题.txt`。
- 每章完成后执行：改前/改后篇幅统计（新章只报改后）→ 禁词/越界词检查 → 距离时间与常识联算 → 三个标题候选与落点检查 → 相邻章衔接 → 文档格式检查 → `git diff --check` → 只暂存本章 → 提交 → 同步远端 → 推送。
- **替换旧版章节时必须做后文残线检查**：列出旧版独有的人名、队伍成员、伤病、道具、地名、选择与章末状态，用 `rg` 检索所有后续已写章节。旧版已经删掉的引入仍被后文引用，或队伍人数、同行关系沿用旧版，均不得合并；须同步改后文或恢复可信引入，并重新校验账本。
- 导演更新 LEDGER：已锁事实、关系状态、不可逆后果、线索已知结论、雷台账、校勘进度。
- 每案末出「读者体验审计」：重复、解释笑点、无后果、人物可替换问题；供老板终审。
- 阅读器发布时自动剔除【章末自报】；写作 Agent 仍须附自报。

## 十八、审计新增退稿门（v12）

- **失败门**：每个 10—20 章单元至少一次主角判断失误，并留下下一章仍需承担的实际代价；只有“原文有边界”而没有损失，不算失败。
- **机制门**：最近四章不得全部使用询问—记录—总结—等待；至少两章必须由追逐、交换、误导、环境反制、关系误判、物件失控或仪式失败推进。
- **向导门**：信息 NPC 必须有独立目标、拒绝条件或交换要求；只负责讲设定、讲完离场，一门不过即退。
- **病程门**：持续危机每两至三章必须出现可观察变化，并影响行动、资源或风险；“仍高热／仍昏沉”原样复读退稿。
- **谜账门**：任务卡记录本章推进或关掉的旧谜；每 30 章至少完成一条阶段性兑现。只增加未知、不改变判断的线索退稿。
- **公式门**：同一章“A不是B，是C”“可以……不能……”各不超过一次；系统固定口癖十二章内不得原样复用；连续两章不得使用同类空悬念结尾。
- **发布门**：章节生产稿只能有一个正文终止分隔线和一份章末自报；正文内部不使用 `---` 场景线。发布前必须运行 `python3 build_reader.py`，并检查 `dist/content/published/` 不含 `【章末自报】` 与 `---`。
